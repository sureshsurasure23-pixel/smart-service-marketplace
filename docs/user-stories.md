# Smart Service Marketplace — User Stories

## 1. Customer User Stories

### US-C01 — Registration
As a customer, I want to create an account so that I can use the marketplace.

### US-C02 — Login
As a customer, I want to securely log in so that I can access my account.

### US-C03 — Profile
As a customer, I want to manage my profile so that my information remains updated.

### US-C04 — Search Services
As a customer, I want to search for services so that I can find the service I need.

### US-C05 — Filter Services
As a customer, I want to filter services by category, price, and rating so that I can quickly find suitable providers.

### US-C06 — View Service
As a customer, I want to view service details so that I can understand what the provider offers.

### US-C07 — View Provider
As a customer, I want to view provider information and reviews so that I can choose a reliable provider.

### US-C08 — Check Availability
As a customer, I want to see available dates and times so that I can select a convenient appointment.

### US-C09 — Book Service
As a customer, I want to book a service so that I can receive the service at my selected time.

### US-C10 — Booking History
As a customer, I want to view my booking history so that I can track my previous and current bookings.

### US-C11 — Cancel Booking
As a customer, I want to cancel a booking when necessary.

### US-C12 — Review Provider
As a customer, I want to rate and review a completed service so that I can share my experience.

### US-C13 — Notifications
As a customer, I want to receive notifications about booking updates so that I know the current status.

### US-C14 — AI Recommendations
As a customer, I want to receive relevant service recommendations so that I can discover suitable services faster.


## 2. Service Provider User Stories

### US-P01 — Provider Registration
As a service provider, I want to register on the platform so that I can offer my services.

### US-P02 — Provider Profile
As a provider, I want to create a professional profile so that customers can learn about me.

### US-P03 — Add Service
As a provider, I want to add services so that customers can book them.

### US-P04 — Edit Service
As a provider, I want to update service information so that customers see accurate details.

### US-P05 — Delete Service
As a provider, I want to remove services that I no longer offer.

### US-P06 — Set Price
As a provider, I want to define service prices so that customers know the expected cost.

### US-P07 — Manage Availability
As a provider, I want to manage my available dates and times so that customers can book suitable slots.

### US-P08 — View Bookings
As a provider, I want to view incoming bookings so that I can manage customer appointments.

### US-P09 — Accept Booking
As a provider, I want to accept booking requests so that customers know their appointment is confirmed.

### US-P10 — Reject Booking
As a provider, I want to reject unsuitable booking requests.

### US-P11 — Update Booking
As a provider, I want to update booking status so that customers know the progress of their service.

### US-P12 — View Reviews
As a provider, I want to view customer reviews so that I can understand customer satisfaction.

### US-P13 — Earnings
As a provider, I want to view basic earnings information so that I can track my business performance.


## 3. Admin User Stories

### US-A01 — Admin Login
As an administrator, I want to securely log in so that only authorized administrators can access the admin dashboard.

### US-A02 — Dashboard
As an administrator, I want to view platform statistics so that I can monitor the marketplace.

### US-A03 — Manage Customers
As an administrator, I want to view and manage customers.

### US-A04 — Manage Providers
As an administrator, I want to view and manage service providers.

### US-A05 — Provider Approval
As an administrator, I want to approve or reject provider registrations so that only valid providers can offer services.

### US-A06 — Manage Categories
As an administrator, I want to create, update, and delete service categories.

### US-A07 — Manage Services
As an administrator, I want to manage services listed on the platform.

### US-A08 — Manage Bookings
As an administrator, I want to monitor bookings so that I can manage platform activity.

### US-A09 — Manage Reviews
As an administrator, I want to monitor reported reviews and inappropriate content.

### US-A10 — Reports
As an administrator, I want to view platform reports so that I can understand marketplace activity.
